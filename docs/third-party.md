# Dependencies and attribution

kavtor is licensed under GNU GPLv3. It uses system Qt 6 and hidapi rather than
vendoring their code. CasparCG is a separate process; casparMIX is distributed
as an additive GPL patch set in its own repository. Optional NDI diagnostics
require a separately installed NDI SDK and runtime; neither is redistributed.

The public source tree includes original SVG controls and project branding.
Third-party reference projects, private media/configuration, Sony manuals and
manual pictogram extracts are excluded. The Sony catalogue stores factual
identifiers and project interpretations with documented operator-review limits.
